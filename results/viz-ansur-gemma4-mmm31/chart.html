How to read this page
  • The filter row scopes every chart, tile and table below it. Changing a filter re-renders all of them against the same slice.
  • Colour means identity, never magnitude: blue is always F, orange is always M, and filtering never repaints the remaining series.
  • Every chart has a table twin. The button above each chart opens it, so no value is reachable only by hovering.
  • Height and weight are stored in inches and pounds in the source file; the dashboard uses the metric conversions derived in tools/build_data.py and shows them in the axis labels.
  • Missing values are kept as missing rather than filled in, and every statistic reports the number of observations it was computed from.
