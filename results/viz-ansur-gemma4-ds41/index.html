ANSUR Anthropometric Dashboard

Distributions and relationships among the ANSUR (U.S. Army) body measurements, for both sexes. Source: data/ansur-full.csv, embedded as ansur/data.js; every figure below (record counts, missing-cell counts, correlations) is computed in the browser from those records. Units are mixed — height in inches, weight in pounds, age in years, and every other body measurement in millimetres — so each axis is labelled with its own unit and raw values from different unit groups never share an axis. Missing measurements are shown as gaps and reported, never imputed.

Values are computed pairwise-complete: each cell uses only the rows where both measurements are present, so a coefficient built on fewer rows is less certain — check the pairwise n. The correlation view (default) is unit-free; the covariance view mixes incompatible units and its cells are therefore colour + tooltip only. Click any cell to load that pair into the scatter plot above.

Textual description: the matrix is a square grid with one row and one column per numeric measurement, so every pair of measurements appears twice. The diagonal is 1 in the correlation view. Stronger positive values are red, stronger negative values are blue, and near-zero values are light grey; each correlation cell also prints its value.
