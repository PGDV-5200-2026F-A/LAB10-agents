Gender encoding is redundant everywhere: Male — teal, circle, solid fill, “M” label, Female — coral, triangle, diagonal hatch, “F” label.

P1 · Measurement scatter

Drag on the plot to brush-select people; the selection dims unselected points and is echoed (labelled) in P3/P4/P5. Contours are a smoothed kernel estimate (bandwidth 20, 12 levels), not observed points. Axis domains are the frozen full-sample extents, so toggling gender never rescales an axis.

P2 · Measure-pair matrix (16 × 16)

Metric

Click (or focus + Enter on) any cell to load that pair into P1. Values use pairwise complete cases per pair. Most measures share a dominant overall-body-size factor, so the r-matrix reads mostly warm; height (in) vs stature (mm) is unit redundancy, not a finding.

P3 · Distribution of Y measure, by gender

Violin width = kernel density (arbitrary units, Gaussian kernel, Silverman bandwidth, fixed 48-point grid over the frozen full-sample extent — so filtered violins stay comparable). Box = q1–q3, thick line = median, whiskers = 1.5×IQR fence, circles = outliers, diamond = mean. Numbers above each violin are exact (not hover-only).

P4 · Age distribution (stacked M/F)

Bin edges are fixed at 15, 20, …, 60 years (never data-derived), so the histogram is stable across filters. Counts above bars are bin totals.

P5 · Parallel coordinates — axis brushes are global filters

Axes are independent per-measure scales in original units (never normalized); vertical position is meaningless across axes. Drag vertically on any axis to filter — every panel and the header tiles recompute, and each axis shows the live surviving n under its label. Lines skip axes with missing values rather than drawing through them. Teal/coral lines highlighted at high opacity = the P1 scatter-brush selection, if any.

P6 · Body-region z-scored violins

This is the only panel where units are deliberately removed: z = (x − mean)/sd computed per measure on the current filtered sample, so size-independent shape differences (ear vs. hand proportions, sexual dimorphism by region) become comparable. Dashed line marks z = 0. The KDE grid is fixed to z ∈ [−3.5, 3.5]; the density axis is shared across all 16 columns.
